# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

组串必须挂在箱变底下报送。每台箱变有**油样化验有效期**：油样过期后，该箱变底下的组串报送一律在拦截口挡回（HTTP 409，提示重新化验），不写队列表、不触发通知。顶栏「油样台账」专页与拦截口读的是同一张表同一列（`transformers.oil_expiry_date`），不存在台账显示过期、另一面仍放行的两张皮。

## 油样规则

- 报送入队前对箱变行加 `SELECT ... FOR UPDATE` 行锁并复查到期日；过期即拦，写 `blocked` 痕迹、更新台账「最近一次拦住理由」。
- 有写权限账号（scanner）可在台账页改到期日、登记续检（续检在原到期日与今天中较晚者之上顺延），续检/改期都留痕。
- 续检与报送撞同一箱变时由同一把行锁串行：结局只有一种，被收下的报送必在续检提交之后，不会一边收下一边还挂过期。
- 工人认领时再次复查油样（兜底：报送后才过期的也不出结论，置为 `blocked`）。
- 旁观账号 watcher 全程只读：报送/续检/改到期日均 403。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领，行锁内复查油样
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/transformers` | 油样台账：各箱变到期日、是否过期、最近拦住理由、最近续检 |
| GET | `/api/transformers/{id}/events` | 该箱变油样痕迹（拦截/续检/改期/报送入队） |
| PUT | `/api/transformers/{id}/expiry` | writer 修改油样到期日（YYYY-MM-DD） |
| POST | `/api/transformers/{id}/renew` | writer 登记油样续检（body 可带 `months`，默认 12） |
| POST | `/api/logs` | writer 报送组串（须带 `transformer_id`）；油样过期返回 409 |
| GET | `/api/logs` | 报送记录（含箱变名、`pending`/`done`/`blocked` 状态） |

## 种子

| 箱变 | 油样到期日 |
|------|-----------|
| 变甲 | 30 天后（有效，可直接报送） |
| 变乙 | 昨天（已过期，其下报送必被拦） |

| 组串 | 所属箱变 | 填充因子 | 结论 |
|------|----------|----------|------|
| 阵列A-串03 | 变甲 | 0.78 | 合格 |
| 阵列B-串11 | 变甲 | 0.61 | 衰减 |

验证路径：变甲有效期内报送入队 → 把到期日改成昨天再送，被 409 拒绝并提示重新化验、台账出现拦住理由 → 登记续检后再送，入队出结论，全部动作在台账痕迹可查。
